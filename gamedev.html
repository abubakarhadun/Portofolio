Proyek Utama

Pixel Odyssey

  • 2D side-scroller
  • Unity
  • Kontrol sentuh
  • Level design

Game 2D dengan lima map bertema: kamar, gurun, hutan, kota neon, dan luar angkasa. Tiap map punya suasana dan karakter sendiri. Latar disusun berlapis supaya terasa punya kedalaman, lalu cuplikan mapnya kurender sebagai video.

Kontrolnya dibuat untuk layar sentuh: tombol kiri, kanan, dan Jump yang besar dan mudah dijangkau jempol.

Genre
Platformer 2D
Engine
Unity
Fokus
Desain level, UI sentuh, suasana tiap map

Game Perang Meriam

  • Tower defense
  • UI intro
  • Animasi hancur

Rekreasi tower defense bergaya Clash Royale. Arenanya berlantai kotak hijau dengan menara di tiap sisi. Pemain mengisi nama di layar intro, lalu menekan Mulai untuk masuk ke arena.

Menara yang hancur pecah menjadi serpihan, supaya pemain langsung paham ada yang berubah di medan.

Genre
Tower defense
Fokus
Layar intro, kamera, umpan balik visual saat menara hancur

Paper Plane

  • Unreal Engine 5
  • Kontrol gerak HP
  • Node.js

Pesawat kertas yang digerakkan dengan memiringkan HP. Sensor orientasi HP dikirim ke Unreal Engine lewat jembatan Node.js, dan level pertamanya berlatar ruang kelas.

Cara kerja jembatan dan potongan kodenya ada di halaman Code. Render adegan kamarnya ada di halaman 3D.

Engine
Unreal Engine 5
Input
Sensor orientasi HP (roll, pitch, yaw)
Level
Ruang kelas

SIM A Simulator

  • Game edukasi
  • Simulasi 3D
  • Unreal Engine 5
  • Group J KBT

Game edukasi untuk latihan ujian SIM A: berkendara di lingkungan 3D, mengenali rambu lalu lintas, dan mengerjakan latihan soal. Dibuat bersama Group J KBT, Informatika Universitas Muhammadiyah Malang.

Produk digital sekali bayar Rp35.000 dengan akses selamanya dan bisa dimainkan tanpa internet. Halaman produk dan pembeliannya ada di situs resmi game.

Edukasi dan simulasi
Engine

Tim
