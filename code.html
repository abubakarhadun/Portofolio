Phone Tracker Bridge

  • Node.js
  • WebSocket
  • UDP
  • Unreal Engine

HP jadi kontroler gerak untuk game Paper Plane. Halaman web di HP membaca sensor orientasi (DeviceOrientation API) dan mengirim roll, pitch, yaw sebagai JSON pada 60 kali per detik. Ada kalibrasi titik nol supaya posisi pegang HP tidak mengubah arah awal.

Server Node.js menerima data lewat WebSocket, lalu meneruskannya sebagai paket UDP ke Unreal Engine di port 8888.

  • HP (PWA)
  • WebSocket :8889
  • server.js
  • UDP :8888
  • Unreal Engine

Web dan Mobile

Sociaverse

Proyek akhir mata kuliah Basis Data: platform media sosial dengan skema Oracle (tabel, sequence, trigger, view, stored procedure, dan package PL/SQL), backend Node.js dengan Express, dan antarmuka HTML, CSS, JavaScript murni.

  • Oracle DB
  • Node.js
  • Express
  • HTML/CSS/JS

MemoWallet

Aplikasi memo teks kaya untuk Android berbasis WebView dengan tampilan nostalgia Android Holo. Menu konteks bawaan diganti toolbar kustom, dan beberapa bug editor sudah kuperbaiki, seperti seleksi teks yang hilang saat ukuran font diganti.

  • Android
  • WebView
  • Rich text

The Vibe Grid

Halaman katalog film untuk praktikum Pemrograman Web. Data diambil dari API TMDB lewat fetch, dan pencarian mengirim HTTP request ke API, bukan sekadar menyaring data di layar. Dilengkapi koleksi Postman untuk menguji endpoint.

  • JavaScript
  • DOM
  • REST API
  • Postman
